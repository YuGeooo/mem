# mem

本项目用于 2026 年考研复习记录。

## 目录组织方式

按「年份 + 科目」建文件夹，一个文件夹放一套真题，命名如 `YYYY年<科目>`（示例：`2024年管综真题/`、`2025年英语二/`）。每个文件夹内按下面约定组织文件：

- **题目**：`paper.md`，一套卷子一个文件，存放从 PDF 提取并规范化后的真题；原始 PDF 与它放在同一文件夹。
- **作答**：`answer<N>.md`（`answer1.md`、`answer2.md` …），按题号顺序拆成多份；每份覆盖一段题号，便于分批复习。
- **作答文件格式**：
  - 顶部用 YAML 头记录 `time`（作答时间）和 `file`（对应该套真题的 PDF）；
  - 判定用 ✅/❌ 标注；错题追加 `### 订正`，写清错因与正确答案。

## 说明

- 新增一套真题时，按上述约定建立 `<年份年科目>/paper.md` 与若干 `answer<N>.md` 即可。
- 英语试卷见：https://pastpapers.cn/kaoyan
