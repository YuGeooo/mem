# mem

本项目用于 2026 年考研复习记录（管综 199、英语二 204），用 Markdown 保存题目、作答、批改与总结。

## 目录

```text
mem/
├── 2024年管综真题/            # 真题：一套卷子一个目录，命名 <年份><科目>
│   ├── paper.md               # 题目（从 PDF 整理，公式用 LaTeX）
│   ├── answer1.md … answer11.md  # 按题号分批的作答 + 批改
│   └── 批改总结.md
├── 2025年英语二/
│   ├── paper.md / answer1.md …
│   ├── 试卷总结.md
│   └── 生词本.md
├── 形式逻辑与综合推理/        # 专项练习：一卷一个题库文件
│   ├── 形式逻辑与综合推理一.md   # 卷一（专项训练 1.1），1–15 题
│   ├── 形式逻辑与综合推理二.md   # 卷二（专项训练 1.2），1–15 题
│   ├── answer1/               # 卷一：answer1-1.md（第 1 批）
│   └── answer2/               # 卷二：answer2-1.md（第 1 批）
└── 数学应用题/                # 专项练习：单卷，按考点编号
    ├── 应用题.md              # 题库
    ├── 待重做.md              # 错题清单
    └── answer1/ … answer10/   # 一场一批题，内含 answer<N>.md
```

## 文件命名

| 场景 | 目录 | 作答文件 | 说明 |
|------|------|----------|------|
| 真题 | `<年份><科目>/` | `answer<N>.md` | 题号顺序分批，一套卷子一个目录 |
| 专项·多卷 | `answer<N>/` | `answer<N>-<M>.md` | **N 恒等于卷号**（卷一 → `answer1`、卷二 → `answer2`），M 是批次号，同一卷内递增 |
| 专项·单卷 | `answer<N>/` | `answer<N>.md` | N 按完成顺序编号（如数学应用题 `answer1`–`answer10`） |

每个 `answer<N>/` 目录下的草稿扫描件统一叫 `草稿本.pdf`，仅存本地。

## 文件格式

- **题目**：`paper.md` 或专项题库 `.md` 只放题目，不写答案、不改题意；专项练习开头注明来源与题量。
- **作答**：顶部 YAML 记 `time`、`file`、`duration`；客观题标 ✅/❌，错题在 `### 订正` 写错因与正确答案。
- **批改**：追加在原作答之后并注明日期，先列「题号 | 你的答案 | 正确答案 | 判定」，再逐题分析、归纳错因与下一步建议。
- **总结**：管综 `批改总结.md`、英语 `试卷总结.md`、词汇 `生词本.md`，并注明统计口径。

批改流程、统计口径、Git 与文风约定的完整细则见 [AGENTS.md](./AGENTS.md)。

## 说明

- 图片（`IMG_*.HEIC`、`images/` 等）与 PDF（真题原卷、草稿扫描）只留本地，已被 `.gitignore` 排除；图片里的批改结论必须写进 Markdown。
- 新增一套真题：建 `<年份><科目>/paper.md` 与若干 `answer<N>.md`；新增一卷专项：建题库 `.md` 与 `answer<卷号>/` 目录。
