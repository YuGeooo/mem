# mem

2026 考研复习记录（管综 199、英语二 204）。题目、作答、批改、总结都用 Markdown 保存，按目录逐套回看。

## 里面有什么

- **2024年管综真题/** — 一套真题：`paper.md` 是题目，`answer1.md`… 是按题号分批的作答与批改，`批改总结.md` 汇总全卷。
- **2025年英语二/** — 英语二试卷与批改，另有 `试卷总结.md`、`生词本.md`。
- **形式逻辑与综合推理/** — 专项训练 1.1、1.2 两卷，一卷一个题库文件；作答分别在 `answer1/`（卷一）、`answer2/`（卷二）。
- **数学应用题/** — 单卷专项，题目按考点编号，`待重做.md` 是错题清单。
- **错题重练/** — 把一次跨卷重练的错题当成独立卷：`paper.md` 题目、`答案速查.md` 答案、`answer<N>.md` 场次，题号在本卷重编并进题库索引；各原卷的「待重做」台账另记重做进度。

## 怎么用

一次练习：做在纸上 → 草稿拍照或扫描 → 转录批改写进对应的 `answer` 文件 → 错题进「待重做」→ 隔天不看批改白纸重做 → 阶段结束写总结。

每份作答文件开头记用时与题目来源；批改固定三段：判定表（题号 / 你的答案 / 正确答案 / 判定）→ 逐题分析 → 错因归纳与下一步建议。
